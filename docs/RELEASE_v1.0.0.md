# JARVIS v1.0.0

## Stateful Personal AI Operating System for Windows

This is the v1.0.0 baseline release of JARVIS: a stateful multimodal personal AI operating system focused on realtime voice, Windows automation, governed tool execution, remote supervision, and persistent memory.

### Highlights

- Gemini Live realtime multimodal cognition
- WASAPI loopback reference audio and echo cancellation
- Windows UI Automation through native COM control patterns
- WhatsApp VoIP/WebRTC voice integration
- Telegram remote supervision and approval flows
- Python cognitive control plane with Node.js execution substrate
- ActionBroker and capability firewall for side-effect governance
- SQLite WAL + FTS5 memory fabric
- Neural 3D web interface
- Automated Python quality gates through GitHub Actions
